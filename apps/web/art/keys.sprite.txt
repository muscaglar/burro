# The picture at an end of a scale, for a part that knows the end by its name: houses and
# flats, calm and buzzy, newer and historic, polished and gritty. Neither end is the good end.
#
# Each is one picture: the picture of that end of its vibe, which ends.sprite.txt draws, set in
# the middle of the canvas an end had while it was two pictures side by side, and on its last
# row. So an end is drawn one way, whichever way a part asks for it. Change the picture there,
# then write its rows here again: test/art.test.ts holds the two to each other.
#
# A picture is named for its end, in the words the service gives the end, in lower case:
# key-calm for Calm. What runs one way and is drawn by no vibe of its own has key-least and
# key-most. An end with no picture of its own has key-blank, which stands beside the heading
# of the page that is not there as well, and is kept as it was for that page. Each is 32 wide
# and 22 high.
# The text is the drawing, one character a pixel. Change it here, then run `npm run gen:art`.
