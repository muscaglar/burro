# Saved evidence

Dated copies of licence terms that could change or disappear: marketplace terms accepted at sign-up, written replies from data owners, pages behind a login.

The text of a standard public licence (OGL, CC0, ODbL and so on) does not need a copy here. The publisher's page that says which licence applies does: save it before launch, and then set `attribution_verified` to true if the wording matches.

A written reply holds a person's name and address, so the reply itself is not saved here. What is saved is a dated note of it: what was asked, what the owner answered, who has read the reply, and where it is kept. A note prints no words of the reply. `registry/README.md` says what a note holds. A note that was not written from the reply says so, and clears nothing.

Name each file `<source-id>-<yyyy-mm-dd>.<ext>`. Do not save anything that contains personal data or account credentials.
